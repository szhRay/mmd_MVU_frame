# 参考文档

本目录集中保存作者制作角色卡前端时需要查阅的说明。日常从项目根目录的 `README.md` 开始，需要细节时再进入对应文档。

- [AI_WORKFLOW.md](AI_WORKFLOW.md) — 面向不懂代码作者的自然语言对话与五组确认流程。
- [AUTHORING.md](AUTHORING.md) — 九个作者入口、变量设计、功能栏、回复状态栏与舞台的编写契约。
- [API.md](API.md) — 项目公开接口及必要的 MMD 新页 SDK 能力。

常规制作以这三份文档为准。只有 API 未覆盖、验证错误无法解释、实际行为与文档不一致，或明确诊断框架时，才继续查阅完整平台规范与 `src/framework/`。
